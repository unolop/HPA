# Paper Figures — Generation Guide

All main figures are generated by running:
```bash
conda run -n zero python analysis/run_paper_figures.py
```
from the repo root. Outputs go to `latex/AnonymousSubmission/LaTeX/figures/`.

Notebook figures must be generated by running the respective notebook and saving
the output manually to `figures/` with the filename indicated below.
