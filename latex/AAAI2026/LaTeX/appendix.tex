\section{Dataset Preparation}
\label{app:data}

Both GPT-4.1-mini-2025-04-14 calls described below use temperature~0, seed~42, and structured JSON schema mode with \texttt{additionalProperties:~false}.
Questions are submitted in batches of 50 per API call.

\subsection{Control Question Extraction Pipeline}
\label{app:ctl}

The generation pipeline produces four variants per question, but human and model comparisons use three: \textbf{Original} (C, unmodified), \textbf{Weaker} (B, \texttt{weaker\_object}), and \textbf{Pronominalized} (A, \texttt{pronominalized}). The \texttt{deictic\_removed} and \texttt{object\_removed} steps are intermediate scaffolding used by the extraction pipeline but excluded from analysis.
The output schema enforces \texttt{\{deictic\_removed, object\_removed, weaker\_object, pronominalized\}} as required string fields.
The system prompt is reproduced verbatim below:

\begin{quote}\small
Generate 4 control variants for each VQA question.
Return ONLY a JSON object \texttt{\{"results":[...]\}}; preserve input order.

\textbf{Rules:}

1) \textit{deictic\_removed}: Remove deictic words (this/that/these/those/here/there)
and spatial markers (left/right/top/bottom/foreground/background) while preserving
grammar. Restructure the sentence if needed to remain fluent.

2) \textit{object\_removed}: Replace the specific object noun with neutral placeholder
``object''. Do not replace pronouns or generic nouns already present.

3) \textit{weaker\_object}: Replace the specific object noun with a broader hypernym
one level up (dog$\to$animal, car$\to$vehicle, drink$\to$beverage, shirt$\to$clothing,
apple$\to$fruit, knife$\to$utensil, sofa$\to$furniture). If no clear hypernym
exists, use ``object''.

4) \textit{pronominalized}: Replace ALL content noun phrases with minimal pronouns.
Grammar-aware rules: attribute (``What color is the dog?'') $\to$ ``What color is it?'';
count (``How many cats are there?'') $\to$ ``How many are there?'';
location (``Where is the phone?'') $\to$ ``Where is it?'';
action (``What is the man doing?'') $\to$ ``What is it doing?'';
yes/no (``Is the dog affectionate?'') $\to$ ``Is it affectionate?'';
multi-NP (``between the girl and the giraffe'') $\to$ ``between them''.
Keep ONLY question words, copula, prepositions, predicate/attribute, and pronouns.
Use ``it''/``they''/``them''---never ``the object''.
\end{quote}

\subsection{Question Taxonomy Extraction}
\label{app:sem_extraction}

Each question is annotated along two axes: \emph{operation type} (what reasoning the question demands) and \emph{entity type} (what semantic field its subject belongs to).
The output schema enforces \texttt{op} and \texttt{ent} as required enumerated string fields.
The system prompt is reproduced verbatim below:

\begin{quote}\small
Extract VQA question semantics from text only; do not invent visual details.
Return ONLY a JSON object \texttt{\{"results":[...]\}} matching the schema exactly; preserve input order.

\textbf{Decision rules:}

1) \textit{op} priority (highest to lowest):
\texttt{text} $>$ \texttt{count} $>$ \texttt{spat} $>$ \texttt{temp} $>$ \texttt{cause} $>$ \texttt{comp} $>$ \texttt{attr} $>$ \texttt{exist} $>$ \texttt{ident} $>$ \texttt{act} $>$ \texttt{know} $>$ \texttt{other}.

2) If \texttt{w=yesno} AND \texttt{op=exist} $\Rightarrow$ \texttt{ans=bool}, \texttt{space=bin}. Other yes/no use \texttt{op} based on content.

3) \texttt{attr} consistency: color$\to$\texttt{ans=color}, \texttt{space=cat}; material$\to$\texttt{mat,cat}; age$\to$\texttt{age,num}; duration$\to$\texttt{dur,num}; count$\to$\texttt{num,num}; name$\to$\texttt{text,cat}; location$\to$\texttt{loc,cat}; type/ident$\to$\texttt{cat,cat}.

4) \texttt{txt=true} iff \texttt{op=text}. \texttt{know=true} iff \texttt{op=know}.

5) \texttt{sp}/\texttt{rel}/\texttt{dx} only if explicit in question.

6) If \texttt{w=where} and \texttt{op} not in \{\texttt{text,know}\} $\Rightarrow$ \texttt{op=spat}, \texttt{attr=loc}, \texttt{ans=loc}, \texttt{space=cat}.
\end{quote}

\subsection{Human Study Protocol and Statistics}
\label{app:human}

A total of 40 participants were included. Participants were recruited via
online student community forums at universities. All procedures were conducted
under an IRB-approved protocol adhering to the Declaration of Helsinki.
Informed consent was obtained prior to participation.

Participants answered text-only blind-instruction questions across the original, weaker-object, and pronominalized formulations in shuffled order ($N{=}339$ per participant).
Participants were compensated at 10,000~KRW per hour.

Summary statistics are reported in Section~\ref{sec:human_data}.
Per-participant median RTs range from 2.6~s to 7.5~s with no extreme outliers (Figure~\ref{fig:human_stats_a}).
Answer length is predominantly single-word (92.6\%; Figure~\ref{fig:human_stats_c}).
Soft abstention is negligible ($<$0.04\% per variant: C\,=\,0.039\%, B\,=\,0.020\%, A\,=\,0.039\%), confirming engaged responding throughout.
Confidence ranges from 1.5 to 4.7 per participant (mean 3.07; Figure~\ref{fig:human_stats}), with
per-variant distributions nearly identical---suggesting question surface form
does not systematically inflate or suppress self-reported certainty.

\subsection{Answer Preprocessing Pipeline}
\label{app:preprocessing}

Human and model responses are preprocessed through the following pipeline.
Human responses (collected in Korean) go through all three steps; model responses (produced in English) skip step~1 and go through steps~2 and~3 only.

\textbf{(1) Translation (human responses only).}
Korean responses are translated to English via GPT-4o-mini using the following prompt:
\begin{quote}\small
\textit{You are a precise translation assistant for VQA data.
Task: Translate the Korean answer to English. Return ONLY the translated answer, nothing else.
Rules: Keep answer concise (similar length to original); use natural English phrasing; if it's a number, color, or simple noun, translate directly; do not add explanations.
QUESTION: \{question\}~~KOREAN ANSWER: \{answer\}~~English:}
\end{quote}

\textbf{(2) VQA normalization.}
Answers are lowercased, punctuation stripped, and articles removed following the standard VQA v2 pipeline \citep{antol2015vqa}.

\textbf{(2b) Verbose response stripping.}
Before normalization, model outputs are cleaned with a hand-crafted cascade applied in order:
(i)~\textit{Think-trace removal}: \texttt{<think>...</think>} blocks are stripped via regex; if reasoning text leaks into the output (e.g.\ the response begins \textit{``Okay let's see\ldots''} or \textit{``Hmm, the user is asking\ldots''}), a recovery pass extracts the final committed answer from explicit cues such as \textit{``the answer is\ldots''} or \textit{``therefore X is the answer''}.
(ii)~\textit{Preamble stripping}: leading wrappers matching patterns such as \textit{``The answer is\ldots''}, \textit{``My final answer is\ldots''}, and \textit{``Answer to the question is\ldots''} are removed, as is any residual \texttt{\textbackslash boxed\{\}} template marker.
This cascade is applied uniformly to all model outputs before the normalization step.

\textbf{(3) Abstention cleaning.}
The shared abstention classifier (Appendix~\ref{app:abstention_classifier}) is applied uniformly to both model and human answers to flag non-substantive responses for exclusion from alignment metrics.
Human abstention after normalization is negligible ($<$0.01\% overall; effectively absent), so HH pairs are minimally affected; filtering primarily removes model-abstaining HM pairs.

\subsection{Abstention Classifier Details}
\label{app:abstention_classifier}

% \input{tables/supp/abstention_keyword_table} % not referenced from main text

The classifier was applied uniformly to both model and human responses.
Human participants were instructed to provide an answer in all cases; the resulting human abstention rate is $<\!0.4\%$ (49 of 13,560 responses), confirming near-complete compliance.
The majority of flagged human responses are standalone \textit{``unknown''} or \textit{``I don't know''} answers concentrated in pronominalized variants (A), where the subject referent has been removed and participants lacked sufficient context to commit to a specific answer.
A small number of false positives occur where \textit{unknown} appears as an adjective within a substantive answer (e.g., \textit{``a sauce of unknown origin''}); these are retained in practice because the overall human abstention rate is negligible.

\section{Pronominalization Degradation by Group}
\label{app:op_degradation_gap}

\subsubsection*{Operation-Level Breakdown}

Table~\ref{tab:op_degradation_gap} reports the class-level degradation gaps and Table~\ref{tab:op_degradation_per_model} the per-model view.
Two operation types dominate:

\textit{Identity} ($\Delta_\mathrm{human}{=}{+}0.19$) triggers consistent over-degradation in SA-LLMs (gap $+0.06$) and modest over-degradation in VLMs (gap $+0.03$), while backbone decoders track the human signal almost exactly (gap $-0.00$).
Figure~\ref{fig:r_combined_ident} shows the mechanism: under full pronominalization, VLMs collapse to a near-uniform answer across all Identity questions ($\sHM$ std drops from $0.146$ to $0.043$), eliminating the per-question variance needed to correlate with $\sHH$; backbone decoders maintain diversity (std $0.146{\to}0.155$), continuing to track which questions humans find harder.

\textit{World Knowledge} ($\Delta_\mathrm{human}{=}{+}0.15$) is the sharpest VLM outlier: VLMs over-degrade by $+0.13$ (driven by strong LLaVA-1.5 and Qwen3-VL excesses; Table~\ref{tab:op_degradation_per_model}), whereas SA-LLMs actually \emph{under}-degrade ($-0.08$)---their corpus-based world-knowledge priors remain active regardless of anchor removal.

\textit{Spatial} questions show uniform over-degradation across all model classes ($+0.045$--$+0.075$), consistent with the Wilcoxon results (Table~\ref{tab:degradation_wilcoxon}: $p{<}.01$ for VLMs and both decoder groups).
\textit{Text Reading} is the clearest reversal: humans improve slightly ($-0.03$) under pronominalization, backbone decoders improve even more ($-0.13$), while VLMs are near neutral ($-0.00$)---reflecting that removing the text anchor hurts models less than humans because models never relied on the anchor to begin with.

This asymmetry is interpretable: text-reading questions depend on OCR of image content that models cannot access in the blind condition; removing the text anchor in the question changes little about a model that was already guessing, whereas human readers lose a cue they had been attending to.

\section{Alignment}
\label{app:scale_variant}

We test multiple sizes for three families: InternVL (1B, 2B, 8B), Qwen3-VL (2B, 4B, 8B, 32B), and Qwen3 SA-LLM (0.6B--32B), with Vicuna and LLaVA-Vicuna compared at 7B vs.\ 13B.
For VLMs and LMs, scale yields no consistent benefit: InternVL peaks at 8B ($\sHM{=}0.620$) but dips at 2B ($0.553$); Qwen3-VL is nearly flat and slightly drops at 32B.

\subsection{Per-Question Difficulty Concordance}
\label{app:alignment_r}

Beyond mean $\sHM$, we measure how well a model tracks \emph{which} questions are harder or easier for humans via the Spearman rank correlation
\begin{equation}
  \pr = \mathrm{Corr}_{\mathrm{Spearman}}\!\bigl(\mathbf{s}_{\text{HM}},\,\mathbf{s}_{\text{HH}}\bigr),
  \label{eq:spearman_r}
\end{equation}
where $\mathbf{s}_{\text{HM}}, \mathbf{s}_{\text{HH}} \in \mathbb{R}^{|\mathcal{Q}|}$ are per-question mean SBERT score vectors across all questions $\mathcal{Q}$, and $\mathbf{s}_{\text{HH}}$ is the mean pairwise human score (low = high human disagreement, i.e.\ a harder question).
The human reference band is computed by leave-one-out over raters: each rater is held out in turn, and $\pr$ is computed between the held-out rater and the remaining panel, giving a p5--p95 band that reflects how much a single human deviates from the group.
A high $\pr$ indicates the model ranks questions in the same relative difficulty order as humans; a low $\pr$ means model difficulty is decoupled from human difficulty even if mean $\sHM$ is acceptable.

\section{Does More Thinking Help?}
\label{app:thinking}

The main text focuses on the Qwen3-8B vs.\ Qwen3-8B~(Think) comparison as the primary case study.
This appendix provides the full scale-level analysis and contextualises an important caveat: thinking mode is not uniformly beneficial, and its effects differ substantially across model sizes.

A critical constraint is that 1.7B and 32B think models convert approximately 60\% of their answers into abstentions---the model declines to answer rather than deliberating---leaving a residual answering subset that is too small and potentially biased (skewed towards easier questions) for a reliable alignment comparison.
At 8B, abstention under think mode remains below 2\%, making it the only size where the think vs.\ no-think comparison is fully interpretable.
At 0.6B, thinking mode has no effect on any metric ($p{=}.317$; the 0.6B think and no-think checkpoints are also effectively the same model).

At 8B, think mode yields a marginal $\sHM$ improvement ($\Delta{=}{+}0.012$, $p{=}.049$) and accuracy enters the human reference band, but difficulty tracking regresses slightly ($\rho{:}~0.807{\to}0.750$), with both values remaining within the human LOO range $[0.629,\,0.846]$.
At 32B, $\rho$ similarly regresses ($0.793{\to}0.734$), consistent with frequent thought-skipping at that scale.

A further consequence of extended reasoning is overconfidence: as shown in Figure~\ref{fig:think_abs_vs_length}(c), longer reasoning traces correlate with higher final-answer token log-probability, meaning models commit more strongly to answers that humans---in the same blind condition---would express with appropriate uncertainty.

\section{Answer Aggregation}
\label{app:aggregation}

We cluster semantically equivalent answers (e.g., ``3'' and ``three'') using
GPT-4o mini \citep{openai2025gpt4o}. Human responses are aggregated into a
confidence-weighted distribution:
\begin{equation}
H(a_k^*) = \frac{\sum_{i:\phi(a_i)=a_k^*} c_i}{\sum_i c_i}
\end{equation}
where $c_i$ is participant $i$'s Likert confidence (normalized to $[0,1]$)
and $\phi$ maps raw answers to canonical forms.
